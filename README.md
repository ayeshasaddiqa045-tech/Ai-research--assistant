# ScholarAI — Smart AI Research Assistant

## Problem Statement
Students and researchers spend hours reading long academic papers and extracting key findings. ScholarAI solves this by automating research summarization, key takeaway extraction, and academic citation suggestions in seconds.

## Key Features
- **Instant Summarization:** Summarizes complex research papers into clean bullet points.
- **Key Findings Extraction:** Identifies main research results automatically.
- **Citation Assistance:** Provides reference structures for academic work.
- **Simple Web Interface:** Clean and responsive UI.

## AI Feature & System Prompt
Powered by **Google Gemini 1.5 Flash**.

**System Prompt Used:**
> "You are ScholarAI, an expert AI Research Assistant. Your task is to analyze academic text or research topics and provide: 1. Key Summary (Bullet points), 2. Main Research Findings, 3. Suggested Academic References / Citations. Be clear, formal, and academic in tone."

## Tech Stack
- Frontend: HTML5, CSS3, JavaScript (ES6+)
- AI Provider: Google Gemini API
- Deployment: Vercel
